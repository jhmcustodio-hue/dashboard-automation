# Prompt padrão — geração de dashboard HTML

Você vai receber dados tabulares (CSV) de um relatório de negócio. Gere um dashboard em HTML
autocontido (sem dependências externas) que:

1. Mostra os principais indicadores (KPIs) do período em destaque no topo.
2. Inclui pelo menos um gráfico (SVG inline ou `<canvas>` com JavaScript vanilla) que visualize a
   evolução dos dados ao longo do tempo.
3. Escreve, em texto corrido, de 2 a 4 parágrafos de insights sobre os dados: tendências,
   variações relevantes, pontos de atenção.
4. Usa uma paleta de cores neutra e profissional, tipografia legível, e funciona bem tanto em
   tela clara quanto escura.

Responda apenas com o HTML completo, sem explicações adicionais antes ou depois.
